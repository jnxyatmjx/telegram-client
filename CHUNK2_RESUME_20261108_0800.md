## Added 2026-11-08 08:05 CST — how to avoid stalling again

- Use ONLY single, simple Bash commands. Multi-operation commands
  (semicolon chains, `&&` chains, parenthesised compounds like
  `(cmake ...; echo ...)`, `head`/`tail` tacked on) are flagged as needing
  approval and will stall when nobody is there to approve. One command
  per Bash call. Check things with separate, simple calls.
- Run the long TDLib build DETACHED so a stream cut cannot kill it:
  `nohup cmake --build build --target tdclient -- -j1 > ~/workspace/tg-client/tdlib-build.log 2>&1 &`
  then poll the log file with simple `tail` calls. Never write build logs
  to /tmp — /tmp is wiped on every VM replacement.
